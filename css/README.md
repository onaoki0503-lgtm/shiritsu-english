# LP CSS

> **最終更新日**: 2026-10-20
> **更新者**: AI (Codex)

## 概要

LPの基礎スタイル、現行の白基調Liquid Glass UI、およびアーカイブページのスタイル。

## フォルダ構成

- `arch_style.css` — SFC LPの既存構造・基礎スタイル。重複していた外部フォントimportを除去
- `liquid.css` — 白い半透明パネル、深い青のボタン、8幅対応、料金表、スケルトン、モーションと低減設定
- `common.css` — アーカイブページ用の共通スタイル
- `themes.css` — アーカイブページ用のテーマ
- `README.md` — 本案内

## デザイン

操作色は `--ui-blue: #000066`。みずほのコズミックブルーの方向性を参考に選んだUIトークン。公式仕様のHEX値として断定しない。参照：https://www.mizuho-fg.co.jp/company/info/brand/b_logo.html 。銀行公式トップのCSS取得は403でできなかったため、公式ブランド説明を参考にした。

新スタイルは `arch_style.css` の後に読み込み、大学別アーカイブには自動適用しない。ローディング中だけ本文を隠し、描画開始時に入力を解放。動きを減らす設定とbackdrop-filter非対応時の白い背景を用意した。

## モバイルCTA整理（2026-10-20）

768px以下で無料相談ボタンを下部固定1つに集約。ヘッダー・ヒーロー・料金欄・メール案内内・フォーム内の追加ボタンを非表示にし、PC表示を維持する。メール案内パネルと未接続フォームの非表示ルールを追加した。
