The Reality

なぜ学校や大手予備校の勉強では
難関私大の英語が読めないのか？

「単語帳を何周もした」「分厚い文法書を解き直した」「長文を読みまくった」…それでも慶應やMARCHの過去問で点数が取れない理由があります。

📚

文法用語の暗記地獄

関係代名詞・分詞構文・仮定法・第5文型…バラバラの文法知識を頭に詰め込んでも、実際の入試長文でどう機能しているかを把握できていません。

⏱️

「感覚読み」で時間切れ

構造を論理的に分解できないため、単語の表面だけを拾って日本語に直そうとし、1文に時間を取られて試験時間内に終わりません。

🏃

日々の学習管理の不在

予備校の授業を週1回受けて「分かった気」になっても、残りの6日間で何をどれだけ自習すべきかの指針がなく、継続できません。

Core Solution

A4用紙1枚にすべてを集約した「Syntax Method」

当塾の講師自身が、英検準2級から自力で勉強し、慶應入試英語満点・IELTS 7.0を達成した最大の武器が「Syntax Method」です。
何百ページもある文法書の内容を、節の結合規則と修飾構造の法則としてA4用紙1枚の統合ルールに圧縮。 これを受講開始から2ヶ月で叩き込むことで、難関大のどんな難解な英文であっても、主語・動詞・修飾節が瞬時に視覚的に浮き彫りになり、スラスラ読める状態を実現します。

従来の非効率な文法学習
  • ✕ 500ページの文法書を最初から丸暗記
  • ✕ 個別の文法問題は解けるが長文で使えない
  • ✕ 英文のどこが主節でどこが修飾節か見失う
  • ✕ 和訳に頼るため試験本番で時間不足に陥る
Syntax Method（当塾の指導）
  • ◎ A4・1枚の統一ルールで全構文を網羅
  • ◎ たった2ヶ月で英文の骨格が立体的に見える
  • ◎ ネイティブと同じ左から右への高速直読直解
  • ◎ 慶應入試やMARCHの超長文で満点・高得点を量産
Instruction System

完全個別・日次伴走マネジメント体制

大手予備校の「教えっぱなし」は絶対にしません。武田塾型の毎日の学習管理に、24時間LINEサポートを融合させた究極の伴走体制です。

1. 毎日の自習メニューを完全指定（迷いゼロ）

志望校合格から逆算し、「今日どの参考書の何ページを、どのように進めるか」を日単位で完全にスケジュール化。生徒は迷わず目の前の学習に100%集中できます。

2. 週1回 マンツーマンオンライン個別面談

単なる進捗確認ではありません。実際に英文を目の前で読んでもらい、「なぜその構造だと判断したのか」を口頭試問。理解が浅い部分は即座にその場で矯正します。

3. LINEで24時間いつでも質問・相談可能

自宅学習中に生じた疑問をその場でスマホから質問可能。講師本人が24時間以内に分かりやすく解説し、立ち止まる時間をゼロにします。

4. 定期実力測定テストで成果を可視化

志望校過去問やオリジナル模試を用い、Syntax Methodの定着度と読解速度を定期的に数値化。確実な偏差値上昇と合格可能性を担保します。

FAQ

よくあるご質問

現在の英語の偏差値が50前後ですが、慶應やMARCHに間に合いますか？ +
十分間に合います。講師自身も元々は英検準2級レベルからスタートし、自力で慶應入試満点・IELTS 7.0まで到達しました。大事なのは才能ではなく「正しい文法構造の理解（Syntax Method）」と「毎日の自学自習の継続」です。1年間の集中学習で確実に合格レベルへ引き上げます。
指導はすべてオンラインで完結しますか？ +
はい、全国どこからでも受講可能です。週1回の個別指導はZoomまたはGoogle Meetで行い、日々の学習計画管理や質問対応はLINEで行います。通塾時間をゼロにし、すべて自習と演習に充てることができます。
無料体験授業ではどんなことをしますか？無理な勧誘はありませんか？ +
現在の志望校、模試の成績、日々の勉強習慣を丁寧にヒアリング（壁打ち）した上で、志望校合格に向けた具体的な年間計画と、Syntax Methodの実際の講義を体験していただきます。お互いに「これなら1年で確実に合格できる」と確信できた場合のみ契約いただきますので、無理な勧誘は一切ございません。
保護者が相談・面談に参加することは可能ですか？ +
もちろん大歓迎です。受験生の学力向上にはご家庭のサポートも重要です。初回の個別相談や日々の進捗状況のご報告など、保護者様とも緊密に連携を取りながら指導を進めます。
