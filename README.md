## 概要

難関私立大学（慶應義塾大学・MARCH等）を目指す受験生・保護者向けのランディングページ群です。  
大学別の出題傾向・悩み・スクールカラーに特化させた完全独立ページ（計7枚＋ハブ）で構成されています。

## アセット構成

- `css/common.css` — レスポンシブレイアウト、タイポグラフィ、カード、ボタン、モーダル
- `css/themes.css` — 各大学のイメージカラーCSS変数（`body.theme-xxx`）
- `js/main.js` — FAQアコーディオン、無料体験授業予約モーダル、スムーズスクロール
