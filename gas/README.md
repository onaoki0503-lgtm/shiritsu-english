## 保存・通知・返信の復旧

受付は台帳保存を通知より先に確定。saved:trueと受付ID一致だけをLPの成功とする。通知失敗でも申込を作り直さない。同じ内容の再送は同じ受付IDを使う。

L列の通知とN列の返信はsent/sending/unknownで管理。sending/unknownは送信結果が曖昧なのでGmail履歴・実行終了を照合してから人が復旧し、自動再送しない。返信は台帳の既存宛先に限定。任意の宛先への送信は受け付けない。メールと台帳は単一トランザクションではないため、厳密な一度だけの配信は保証しない。

公開受付は簡易全体制限として1時間30件、計測は新規PV1日5000件。旧版デプロイの無効化は今回独立に再確認していない。今後の機能変更時に、既存デプロイ・共有範囲を差分確認する。
