# SFC生の英語塾 - GAS通知 ＆ アクセス分析API セットアップ手順書

このGoogle Apps Script（GAS）スクリプト（`Code.gs`）を使用することで、**サーバー費用0円**で以下の機能を完全自動化できます：

1. **フォーム送信時に講師のメール（Gmail）へ即時通知**
2. **フォーム送信時に講師のLINEへ即時プッシュ通知**
3. **Googleスプレッドシートへのお問い合わせ自動台帳記録**
4. **LP訪問者のスクロール深度（25%/50%/75%/100%）と閲覧数の自動記録**
5. **管理者ダッシュボード（`dashboard.html`）への集計データリアルタイム提供**

---

## 🚀 5分で完了する導入手順

### ステップ1: Google スプレッドシートを新規作成
1. Google ドライブで [新規] → [Google スプレッドシート] を作成します。
2. スプレッドシート名を **「SFC生の英語塾_データ管理台帳」** などに設定します。

### ステップ2: Apps Scriptエディタを開く
1. スプレッドシート上部メニューの **[拡張機能]** → **[Apps Script]** をクリックします。
2. 開いたエディタ内のコードをすべて削除し、同封の `Code.gs` の内容を丸ごと貼り付けます。

### ステップ3: 設定項目（メールアドレス・LINE）を入力
`Code.gs` の先頭にある `CONFIG` オブジェクトを編集します：

```javascript
const CONFIG = {
  // 問い合わせ通知を受け取る講師のメールアドレス
  NOTIFICATION_EMAIL: "o.naoki0503@intakingresources.com", 
  
  // LINE Notifyで通知を受け取る場合（トークンを入力）
  // 取得方法: https://notify-bot.line.me/ にアクセスし、「マイページ」→「トークンを発行する」でグループまたは自分宛のトークンを発行
  LINE_NOTIFY_TOKEN: "ここに発行したLINE_NOTIFY_TOKENを貼り付け", 
  ...
};
```

※ LINE通知がまだ準備できていない場合は、空欄 `""` のままでもメール通知とスプレッドシート記録は正常に動作します。

### ステップ4: ウェブアプリとしてデプロイ
1. エディタ右上の青いボタン **[デプロイ]** → **[新しいデプロイ]** をクリックします。
2. 左側の歯車アイコンをクリックし、**[ウェブアプリ]** を選択します。
3. 次の通り設定します：
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`（※LPやダッシュボードから通信できるようにするため必ず「全員」を選択）
4. **[デプロイ]** ボタンを押し、初回のみ「アクセスを承認」画面が出るので、ご自身のGoogleアカウントを選択して承認します。
5. デプロイ完了後に表示される **「ウェブアプリのURL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

### ステップ5: LPおよびダッシュボードにURLを設定
1. **LP（index.html / sfc.html）**:
   - `js/tracker.js` および `js/arch.js` 内の `GAS_ENDPOINT_URL` にコピーしたURLを設定します。
2. **ダッシュボード（dashboard.html）**:
   - ブラウザで `dashboard.html` を開き、画面右上の「API設定」ボタンを押してコピーしたURLを貼り付けて保存します。
   - スプレッドシートの集計データ（閲覧数、スクロール深度、問い合わせ一覧）が自動的に読み込まれます！
