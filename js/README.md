# LP JavaScript

> **最終更新日**: 2026-10-22
> **更新者**: AI (Codex)

## 概要

SFCのLPの表示・申込・アクセス計測と、アーカイブページ用スクリプト。

## フォルダ構成

- `arch.js` — スクロール進捗、FAQ、アンカー移動、保存確認・受付ID付きの申込処理
- `liquid.js` — 全画面スケルトン、モバイルメニュー、カード表示、反射・波紋、演出停止、単一モバイルCTAによるサイト内フォームへの移動・送信
- `liquid.browser.test.cjs` — Playwrightによる8画面幅・22項目のデザイン／操作回帰テスト
- `tracker.js` — ページ閲覧IDによるスクロール・閲覧計測。公開設定を使用
- `site-config.js` — 全訪問者共通の公開受付URL・管理専用URL（先生から2026-10-22受領したURLを設定。秘密鍵を入れない）
- `form.test.cjs` — 送信失敗・受付ID照合・再送・希望日時・個人情報非保存のNodeテスト
- `main.js` — アーカイブLP用の既存スクリプト
- `README.md` — 本案内

## 接続

設定・受入テストは `../gas/README.md` を参照。ブラウザのlocalStorageに生徒情報を蓄積しない。

## デザイン検証

`node liquid.browser.test.cjs`（このフォルダで実行）。別途LPフォルダのローカルHTTPサーバーを起動する。既定プレビューは `http://127.0.0.1:8766`。環境に応じ `SFC_PREVIEW_URL`、`SFC_PLAYWRIGHT_MODULE`、`SFC_CHROME` にプレビューURL・Playwrightモジュール・Chrome実行ファイルを指定する。実GASへの送信は行わない。

サイト内フォームを常時表示し、スマホは固定ボタンで移動と送信を兼用する。PCの送信ボタンは維持。相談内容は必須、希望日時は任意で本文へ付記する。受付URLが空欄・通信失敗なら完了表示せず入力を保持。受付番号が一致した保存応答だけを成功とする。2026-10-22、先生の公開用・管理用URLへ接続して公開作業中。初回テストの保存応答が未確認となったが、同じ内容の再送で受付番号一致の成功表示とリセットを確認。追加の直接再送試験は自動レビュー拒否で未実施。台帳・通知の実照合は先生へ依頼する。`node js/form.test.cjs`（LPフォルダ）3件合格。ブラウザ回帰スクリプトは新導線に更新済みだが、この改修では未実行。
